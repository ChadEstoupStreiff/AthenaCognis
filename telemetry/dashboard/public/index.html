The privacy pledge

  • Opt-in only. Nothing is sent until the instance owner says yes.
  • Counters, not content. We receive numbers — never file names, text, prompts or contacts.
  • No identity. Each instance is a random, signed UUID. No IP is stored with the data.
  • Open source. The collector and this dashboard live in the GodAssistant repository.
